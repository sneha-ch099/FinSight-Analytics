# MarketLens Testing Checklist
- [ ] App opens with `.venv\Scripts\python.exe main.py`.
- [ ] Three or more stocks can be selected.
- [ ] Invalid or reversed dates show a validation message.
- [ ] Historical online data loads for a valid range.
- [ ] All four chart types work.
- [ ] KPI cards, scorecard and insights update after analysis.
- [ ] Latest quote refresh displays data or a clear unavailable message.
- [ ] Auto-check can be enabled and disabled.
- [ ] CSV export creates a readable file.
- [ ] Network failures are handled with a clear message.
- [ ] `build.bat` succeeds on Windows.
- [ ] `dist\FinanceProject.exe` opens directly with internet access.

Record actual results; do not mark checks passed until you run them.
